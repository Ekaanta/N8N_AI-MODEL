# N8N AI Model

An AI-powered automation system built with n8n that processes articles, generates AI-based summaries and insights, and stores the results automatically.

### Features

* Automated article processing
* AI-powered summarization
* AI-generated insights and analysis
* Google Sheets data storage
* Automated email reporting
* Webhook-based workflow trigger

### Technologies

* n8n
* Python
* OpenAI API
* Google Sheets
* Webhooks
* AI Agents

### Workflow

Article Input → AI Processing → Summary & Insights → Google Sheets → Email Report
